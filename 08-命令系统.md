# 第6章：命令系统

## 6.1 命令框架设计

Claude Code 的命令系统采用模块化、可扩展的架构设计，支持多种命令类型和加载来源。整个系统围绕 `/command [args]` 的斜杠命令语法构建，提供了丰富的内置命令和灵活的扩展机制。

### 6.1.1 命令类型定义

命令系统定义了三种核心命令类型，位于 `src/types/command.ts`：

```typescript
// 命令基础属性
type CommandBase = {
  name: string                    // 命令名称
  description: string             // 命令描述
  aliases?: string[]              // 命令别名
  isEnabled?: () => boolean       // 动态启用状态
  isHidden?: boolean              // 是否隐藏
  argumentHint?: string           // 参数提示
  whenToUse?: string              // 使用场景说明
  version?: string                // 命令版本
  immediate?: boolean             // 是否立即执行
  isSensitive?: boolean           // 是否敏感命令
  userInvocable?: boolean         // 用户是否可调用
  loadedFrom?: string             // 加载来源
  availability?: CommandAvailability[] // 可用性限制
}

// 完整命令类型
type Command = CommandBase &
  (PromptCommand | LocalCommand | LocalJSXCommand)
```

**三种命令类型**：

1. **PromptCommand** - 提示命令类型
   - 将命令内容展开为发送给模型的提示
   - 支持 `context: 'inline' | 'fork'` 执行上下文
   - 可指定 `allowedTools`、`model`、`effort` 等参数

2. **LocalCommand** - 本地命令类型
   - 执行本地异步操作，返回文本或压缩结果
   - 支持 `supportsNonInteractive` 非交互模式

3. **LocalJSXCommand** - JSX 命令类型
   - 返回 React JSX 组件用于 UI 渲染
   - 支持交互式界面（如选择器、表单等）

### 6.1.2 命令来源层次

命令系统支持从多个来源加载命令，形成分层的命令供应体系：

```
┌─────────────────────────────────────────────────────────────┐
│                      命令来源层次                            │
├─────────────────────────────────────────────────────────────┤
│  1. Bundled Skills     - 内置打包技能                        │
│  2. Builtin Plugins    - 内置插件技能                        │
│  3. Skill Directories  - 技能目录 (.claude/skills/)          │
│  4. Workflow Commands  - 工作流命令                          │
│  5. Plugin Commands    - 插件命令                            │
│  6. Plugin Skills      - 插件技能                            │
│  7. Built-in Commands  - 核心内置命令                        │
└─────────────────────────────────────────────────────────────┘
```

**加载来源标识** (`loadedFrom` 字段)：
- `bundled` - 打包内置技能
- `skills` - 技能目录加载
- `plugin` - 插件提供
- `managed` - 托管策略
- `mcp` - MCP 服务器提供
- `commands_DEPRECATED` - 旧版命令目录

### 6.3.2 斜杠命令解析

`src/utils/slashCommandParsing.ts` 提供基础的命令解析：

```typescript
export type ParsedSlashCommand = {
  commandName: string
  args: string
  isMcp: boolean
}

export function parseSlashCommand(input: string): ParsedSlashCommand | null {
  const trimmedInput = input.trim()

  if (!trimmedInput.startsWith('/')) {
    return null
  }

  const withoutSlash = trimmedInput.slice(1)
  const words = withoutSlash.split(' ')

  let commandName = words[0]
  let isMcp = false
  let argsStartIndex = 1

  // 检测 MCP 命令 (第二个词是 '(MCP)')
  if (words.length > 1 && words[1] === '(MCP)') {
    commandName = commandName + ' (MCP)'
    isMcp = true
    argsStartIndex = 2
  }

  const args = words.slice(argsStartIndex).join(' ')

  return { commandName, args, isMcp }
}
```

### 6.3.3 命令队列管理

命令通过统一的队列系统进行管理，支持优先级调度：

**队列数据结构**：
```typescript
type QueuedCommand = {
  value: string | ContentBlockParam[]
  mode: PromptInputMode
  priority: QueuePriority  // 'now' | 'next' | 'later'
  isMeta?: boolean
  skipSlashCommands?: boolean
  bridgeOrigin?: boolean
}
```

**队列操作** (`src/utils/messageQueueManager.ts`)：

```typescript
// 入队操作
export function enqueue(command: QueuedCommand): void {
  commandQueue.push({ ...command, priority: command.priority ?? 'next' })
  notifySubscribers()
}

// 优先级出队
export function dequeue(filter?: (cmd: QueuedCommand) => boolean): QueuedCommand | undefined {
  // 按优先级查找: now > next > later
  let bestIdx = -1
  let bestPriority = Infinity
  for (let i = 0; i < commandQueue.length; i++) {
    const cmd = commandQueue[i]
    if (filter && !filter(cmd)) continue
    const priority = PRIORITY_ORDER[cmd.priority ?? 'next']
    if (priority < bestPriority) {
      bestIdx = i
      bestPriority = priority
    }
  }
  // ... 出队并返回
}
```

**优先级说明**：
- `now` - 最高优先级，立即执行
- `next` - 默认优先级，用户输入
- `later` - 低优先级，任务通知

### 6.4.3 命令创建流程

技能命令通过 `createSkillCommand` 创建：

```typescript
export function createSkillCommand({
  skillName,
  displayName,
  description,
  markdownContent,
  allowedTools,
  argumentNames,
  source,
  baseDir,
  loadedFrom,
  hooks,
  executionContext,
  paths,
  effort,
  ...,
}): Command {
  return {
    type: 'prompt',
    name: skillName,
    description,
    allowedTools,
    argNames: argumentNames.length > 0 ? argumentNames : undefined,
    whenToUse,
    model,
    context: executionContext,
    effort,
    paths,
    contentLength: markdownContent.length,
    isHidden: !userInvocable,
    progressMessage: 'running',
    userFacingName() {
      return displayName || skillName
    },
    source,
    loadedFrom,
    hooks,
    skillRoot: baseDir,
    async getPromptForCommand(args, toolUseContext) {
      let finalContent = markdownContent

      // 参数替换
      finalContent = substituteArguments(finalContent, args, true, argumentNames)

      // 环境变量替换
      finalContent = finalContent.replace(/\$\{CLAUDE_SKILL_DIR\}/g, baseDir)
      finalContent = finalContent.replace(/\$\{CLAUDE_SESSION_ID\}/g, sessionId)

      // 执行内联 shell 命令
      if (loadedFrom !== 'mcp') {
        finalContent = await executeShellCommandsInPrompt(finalContent, ...)
      }

      return [{ type: 'text', text: finalContent }]
    },
  }
}
```

### 6.4.4 动态技能发现

系统支持在运行时动态发现和加载技能：

```typescript
// 从文件路径发现技能目录
export async function discoverSkillDirsForPaths(
  filePaths: string[],
  cwd: string,
): Promise<string[]> {
  const newDirs: string[] = []

  for (const filePath of filePaths) {
    let currentDir = dirname(filePath)

    // 向上遍历到 cwd
    while (currentDir.startsWith(resolvedCwd + pathSep)) {
      const skillDir = join(currentDir, '.claude', 'skills')

      if (!dynamicSkillDirs.has(skillDir)) {
        dynamicSkillDirs.add(skillDir)
        try {
          await fs.stat(skillDir)
          if (!await isPathGitignored(currentDir, resolvedCwd)) {
            newDirs.push(skillDir)
          }
        } catch {
          // 目录不存在
        }
      }
      currentDir = dirname(currentDir)
    }
  }

  // 按深度排序（深的优先）
  return newDirs.sort((a, b) => b.split(pathSep).length - a.split(pathSep).length)
}
```

### 6.4.5 条件技能激活

export function activateConditionalSkillsForPaths(
  filePaths: string[],
  cwd: string,
): string[] {
  const activated: string[] = []

  for (const [name, skill] of conditionalSkills) {
    if (!skill.paths || skill.paths.length === 0) continue

    const skillIgnore = ignore().add(skill.paths)
    for (const filePath of filePaths) {
      const relativePath = relative(cwd, filePath)

      if (skillIgnore.ignores(relativePath)) {
        // 激活技能
        dynamicSkills.set(name, skill)
        conditionalSkills.delete(name)
        activated.push(name)
        break
      }
    }
  }

  return activated
}
```

### 6.4.6 Fork 执行上下文

技能可以配置为在子代理中执行：

// context: fork 配置
async function executeForkedSlashCommand(
  command: Command & PromptCommand,
  args: string,
  context: ProcessUserInputContext,
): Promise<SlashCommandResult> {
  const agentId = createAgentId()

  // 准备 fork 上下文
  const { skillContent, modifiedGetAppState, baseAgent, promptMessages } =
    await prepareForkedCommandContext(command, args, context)

  // 运行子代理
  const agentMessages: Message[] = []
  for await (const message of runAgent({
    agentDefinition: { ...baseAgent, effort: command.effort },
    promptMessages,
    toolUseContext: { ...context, getAppState: modifiedGetAppState },
    canUseTool,
    querySource: 'agent:custom',
  })) {
    agentMessages.push(message)
  }

  // 提取结果
  const resultText = extractResultText(agentMessages, 'Command completed')

  return {
    messages: [
      createUserMessage({ content: `/${command.name} ${args}` }),
      createUserMessage({ content: `<local-command-stdout>${resultText}</local-command-stdout>` })
    ],
    shouldQuery: false,
    command,
    resultText,
  }
}
```

**Fork 上下文优势**：
- 独立的上下文和令牌预算
- 与主会话隔离执行
- 支持并行执行多个任务
- 适用于长时间运行的技能

## 总结

Claude Code 的命令系统设计体现了以下核心原则：

1. **模块化设计** - 三种命令类型覆盖不同使用场景
2. **延迟加载** - 命令实现按需加载，优化启动性能
3. **多源加载** - 支持内置、插件、技能目录等多种来源
4. **优先级队列** - 智能调度不同优先级的命令
5. **可扩展性** - 通过 SKILL.md 轻松定义自定义命令
6. **条件激活** - 基于路径模式动态启用相关技能

这种架构设计使得 Claude Code 既拥有丰富的内置功能，又具备强大的扩展能力，用户可以根据需要创建和组织自己的命令集合。
