# 第12章：历史记录与记忆系统

## 概述

Claude Code 实现了一套完整的持久化记忆系统，使 AI 助手能够在多次会话之间保持对用户偏好、项目背景和关键决策的记忆。该系统由两个核心组件构成：

1. **会话历史管理**：命令行历史的持久化存储与检索
2. **记忆系统（Memdir）**：基于文件系统的结构化记忆存储与智能检索

本章深入分析这两个系统的设计理念、实现细节和工作机制。

### 12.1.3 历史写入机制

历史写入采用异步批量刷新策略，平衡性能与数据安全：

```typescript
// src/history.ts

let pendingEntries: LogEntry[] = []      // 待刷新的条目
let isWriting = false                     // 写入锁
let currentFlushPromise: Promise<void> | null = null
let lastAddedEntry: LogEntry | null = null

/**
 * 添加命令到历史记录
 * 支持字符串或完整的 HistoryEntry 对象
 */
export function addToHistory(command: HistoryEntry | string): void {
  // 跳过由 Claude Code 生成的 tmux 会话的历史
  if (isEnvTruthy(process.env.CLAUDE_CODE_SKIP_PROMPT_HISTORY)) {
    return
  }

  void addToPromptHistory(command)
}

async function addToPromptHistory(command: HistoryEntry | string): Promise<void> {
  const entry = typeof command === 'string'
    ? { display: command, pastedContents: {} }
    : command

  // 处理粘贴内容：小文本内联，大文本外部存储
  const storedPastedContents: Record<number, StoredPastedContent> = {}
  if (entry.pastedContents) {
    for (const [id, content] of Object.entries(entry.pastedContents)) {
      if (content.type === 'image') continue  // 图片单独存储

      if (content.content.length <= MAX_PASTED_CONTENT_LENGTH) {
        // 小文本：内联存储
        storedPastedContents[Number(id)] = {
          id: content.id,
          type: content.type,
          content: content.content,
          mediaType: content.mediaType,
          filename: content.filename,
        }
      } else {
        // 大文本：计算哈希，异步写入外部存储
        const hash = hashPastedText(content.content)
        storedPastedContents[Number(id)] = {
          id: content.id,
          type: content.type,
          contentHash: hash,
          mediaType: content.mediaType,
          filename: content.filename,
        }
        void storePastedText(hash, content.content)  // Fire-and-forget
      }
    }
  }

  // 构建日志条目
  const logEntry: LogEntry = {
    ...entry,
    pastedContents: storedPastedContents,
    timestamp: Date.now(),
    project: getProjectRoot(),
    sessionId: getSessionId(),
  }

  pendingEntries.push(logEntry)
  lastAddedEntry = logEntry
  currentFlushPromise = flushPromptHistory(0)
}
```

### 12.1.4 历史刷新策略

```typescript
const MAX_HISTORY_ITEMS = 100  // 最大历史条目数

async function flushPromptHistory(retries: number): Promise<void> {
  if (isWriting || pendingEntries.length === 0) return

  // 防止无限重试
  if (retries > 5) return

  isWriting = true

  try {
    await immediateFlushHistory()
  } finally {
    isWriting = false

    // 如果刷新期间有新条目，延迟后再次刷新
    if (pendingEntries.length > 0) {
      await sleep(500)
      void flushPromptHistory(retries + 1)
    }
  }
}

async function immediateFlushHistory(): Promise<void> {
  if (pendingEntries.length === 0) return

  const historyPath = join(getClaudeConfigHomeDir(), 'history.jsonl')

  // 确保文件存在
  await writeFile(historyPath, '', { encoding: 'utf8', mode: 0o600, flag: 'a' })

  // 获取文件锁，防止并发写入
  const release = await lock(historyPath, { stale: 10000, retries: { retries: 3, minTimeout: 50 } })

  try {
    const jsonLines = pendingEntries.map(entry => jsonStringify(entry) + '\n')
    pendingEntries = []
    await appendFile(historyPath, jsonLines.join(''), { mode: 0o600 })
  } finally {
    await release()
  }
}
```

### 12.1.5 历史读取与检索

**上箭头历史读取**：

```typescript
/**
 * 获取当前项目的历史条目
 * 当前会话的条目优先，然后是其他会话的条目
 */
export async function* getHistory(): AsyncGenerator<HistoryEntry> {
  const currentProject = getProjectRoot()
  const currentSession = getSessionId()
  const otherSessionEntries: LogEntry[] = []
  let yielded = 0

  for await (const entry of makeLogEntryReader()) {
    if (!entry || typeof entry.project !== 'string') continue
    if (entry.project !== currentProject) continue

    if (entry.sessionId === currentSession) {
      yield await logEntryToHistoryEntry(entry)
      yielded++
    } else {
      otherSessionEntries.push(entry)
    }

    if (yielded + otherSessionEntries.length >= MAX_HISTORY_ITEMS) break
  }

  // 补充其他会话的条目
  for (const entry of otherSessionEntries) {
    if (yielded >= MAX_HISTORY_ITEMS) return
    yield await logEntryToHistoryEntry(entry)
    yielded++
  }
}
```

**Ctrl+R 时间戳历史搜索**：

```typescript
/**
 * 带时间戳的历史，用于 Ctrl+R 搜索选择器
 * 按显示文本去重，最新优先
 */
export async function* getTimestampedHistory(): AsyncGenerator<TimestampedHistoryEntry> {
  const currentProject = getProjectRoot()
  const seen = new Set<string>()

  for await (const entry of makeLogEntryReader()) {
    if (!entry || typeof entry.project !== 'string') continue
    if (entry.project !== currentProject) continue
    if (seen.has(entry.display)) continue
    seen.add(entry.display)

    yield {
      display: entry.display,
      timestamp: entry.timestamp,
      resolve: () => logEntryToHistoryEntry(entry),  // 懒加载
    }

    if (seen.size >= MAX_HISTORY_ITEMS) return
  }
}
```

### 12.1.6 粘贴内容引用解析

Claude Code 使用特殊格式标记粘贴内容，支持历史恢复时还原：

```typescript
// 粘贴文本引用格式
// [Pasted text #1]           - 单行文本
// [Pasted text #2 +10 lines] - 多行文本

export function formatPastedTextRef(id: number, numLines: number): string {
  if (numLines === 0) return `[Pasted text #${id}]`
  return `[Pasted text #${id} +${numLines} lines]`
}

export function formatImageRef(id: number): string {
  return `[Image #${id}]`
}

// 解析输入中的引用
export function parseReferences(
  input: string,
): Array<{ id: number; match: string; index: number }> {
  const referencePattern =
    /\[(Pasted text|Image|\.\.\.Truncated text) #(\d+)(?: \+\d+ lines)?(\.)*\]/g
  const matches = [...input.matchAll(referencePattern)]
  return matches
    .map(match => ({
      id: parseInt(match[2] || '0'),
      match: match[0],
      index: match.index,
    }))
    .filter(match => match.id > 0)
}

// 展开粘贴文本引用
export function expandPastedTextRefs(
  input: string,
  pastedContents: Record<number, PastedContent>,
): string {
  const refs = parseReferences(input)
  let expanded = input
  // 从后向前替换，保持偏移有效
  for (let i = refs.length - 1; i >= 0; i--) {
    const ref = refs[i]!
    const content = pastedContents[ref.id]
    if (content?.type !== 'text') continue
    expanded =
      expanded.slice(0, ref.index) +
      content.content +
      expanded.slice(ref.index + ref.match.length)
  }
  return expanded
}
```

### 12.1.7 历史撤销机制

支持在用户中断（Esc）时撤销最近的历史条目：

```typescript
const skippedTimestamps = new Set<number>()

/**
 * 撤销最近的 addToHistory 调用
 * 用于自动恢复中断时，语义上撤销提交
 */
export function removeLastFromHistory(): void {
  if (!lastAddedEntry) return
  const entry = lastAddedEntry
  lastAddedEntry = null

  // 快速路径：从待刷新缓冲区移除
  const idx = pendingEntries.lastIndexOf(entry)
  if (idx !== -1) {
    pendingEntries.splice(idx, 1)
  } else {
    // 慢速路径：已刷新到磁盘，加入跳过集合
    skippedTimestamps.add(entry.timestamp)
  }
}
```

## 12.2 记忆系统架构

### 12.2.1 系统设计理念

Claude Code 的记忆系统（Memdir）采用基于文件系统的持久化存储，核心设计理念包括：

1. **文件优先**：记忆以 Markdown 文件形式存储，便于版本控制和人工审查
2. **类型约束**：限制为四种记忆类型，避免无限制存储导致的信息冗余
3. **可推导排除**：代码模式、架构、Git 历史等可从项目状态推导的内容不存储
4. **双层作用域**：支持私有记忆和团队共享记忆

### 12.2.2 目录结构

```
~/.claude/
├── projects/
│   └── <sanitized-project-path>/
│       └── memory/
│           ├── MEMORY.md           # 入口索引文件
│           ├── user_profile.md     # 用户类型记忆
│           ├── feedback_testing.md # 反馈类型记忆
│           ├── project_context.md  # 项目类型记忆
│           ├── reference_links.md  # 引用类型记忆
│           ├── logs/               # 助手模式日志目录
│           │   └── 2026/
```

### 12.2.3 路径解析机制

```typescript
// src/memdir/paths.ts

/**
 * 获取自动记忆目录路径
 * 解析顺序：
 *   1. CLAUDE_COWORK_MEMORY_PATH_OVERRIDE 环境变量
 *   2. settings.json 中的 autoMemoryDirectory
 *   3. <memoryBase>/projects/<sanitized-git-root>/memory/
 */
export const getAutoMemPath = memoize(
  (): string => {
    const override = getAutoMemPathOverride() ?? getAutoMemPathSetting()
    if (override) return override

    const projectsDir = join(getMemoryBaseDir(), 'projects')
    return (
      join(projectsDir, sanitizePath(getAutoMemBase()), 'memory') + sep
    ).normalize('NFC')
  },
  () => getProjectRoot(),  // 按项目根路径缓存
)

/**
 * 获取记忆存储基础目录
 * 解析顺序：
 *   1. CLAUDE_CODE_REMOTE_MEMORY_DIR 环境变量
 *   2. ~/.claude（默认配置目录）
 */
export function getMemoryBaseDir(): string {
  if (process.env.CLAUDE_CODE_REMOTE_MEMORY_DIR) {
    return process.env.CLAUDE_CODE_REMOTE_MEMORY_DIR
  }
  return getClaudeConfigHomeDir()
}

/**
 * 检查路径是否在自动记忆目录内
 */
export function isAutoMemPath(absolutePath: string): boolean {
  const normalizedPath = normalize(absolutePath)
  return normalizedPath.startsWith(getAutoMemPath())
}
```

### 12.2.4 自动记忆启用检查

```typescript
/**
 * 检查自动记忆功能是否启用
 * 优先级链（第一个定义的生效）：
 *   1. CLAUDE_CODE_DISABLE_AUTO_MEMORY 环境变量
 *   2. CLAUDE_CODE_SIMPLE (--bare 模式)
 *   3. CCR 无持久存储模式
 *   4. settings.json 中的 autoMemoryEnabled
 *   5. 默认：启用
 */
export function isAutoMemoryEnabled(): boolean {
  const envVal = process.env.CLAUDE_CODE_DISABLE_AUTO_MEMORY
  if (isEnvTruthy(envVal)) return false
  if (isEnvDefinedFalsy(envVal)) return true
  if (isEnvTruthy(process.env.CLAUDE_CODE_SIMPLE)) return false
  if (isEnvTruthy(process.env.CLAUDE_CODE_REMOTE) &&
      !process.env.CLAUDE_CODE_REMOTE_MEMORY_DIR) {
    return false
  }
  const settings = getInitialSettings()
  if (settings.autoMemoryEnabled !== undefined) {
    return settings.autoMemoryEnabled
  }
  return true
}
```

### 12.3.5 MEMORY.md 入口文件

MEMORY.md 是记忆系统的索引文件，最多 200 行或 25KB：

```typescript
// src/memdir/memdir.ts

export const ENTRYPOINT_NAME = 'MEMORY.md'
export const MAX_ENTRYPOINT_LINES = 200
export const MAX_ENTRYPOINT_BYTES = 25_000

/**
 * 截断 MEMORY.md 内容到行数和字节限制
 */
export function truncateEntrypointContent(raw: string): EntrypointTruncation {
  const trimmed = raw.trim()
  const contentLines = trimmed.split('\n')
  const lineCount = contentLines.length
  const byteCount = trimmed.length

  const wasLineTruncated = lineCount > MAX_ENTRYPOINT_LINES
  const wasByteTruncated = byteCount > MAX_ENTRYPOINT_BYTES

  if (!wasLineTruncated && !wasByteTruncated) {
    return { content: trimmed, lineCount, byteCount, wasLineTruncated, wasByteTruncated }
  }

  // 先按行截断
  let truncated = wasLineTruncated
    ? contentLines.slice(0, MAX_ENTRYPOINT_LINES).join('\n')
    : trimmed

  // 再按字节截断（在最后一个换行符处）
  if (truncated.length > MAX_ENTRYPOINT_BYTES) {
    const cutAt = truncated.lastIndexOf('\n', MAX_ENTRYPOINT_BYTES)
    truncated = truncated.slice(0, cutAt > 0 ? cutAt : MAX_ENTRYPOINT_BYTES)
  }

  return {
    content: truncated + `\n\n> WARNING: ${ENTRYPOINT_NAME} is too large. Keep index entries concise.`,
    lineCount,
    byteCount,
    wasLineTruncated,
    wasByteTruncated,
  }
}
```

## 12.4 记忆检索与应用

### 12.4.1 记忆扫描机制

```typescript
// src/memdir/memoryScan.ts

export type MemoryHeader = {
  filename: string
  filePath: string
  mtimeMs: number
  description: string | null
  type: MemoryType | undefined
}

const MAX_MEMORY_FILES = 200
const FRONTMATTER_MAX_LINES = 30

/**
 * 扫描记忆目录中的 .md 文件，读取 frontmatter，返回按修改时间排序的列表
 */
export async function scanMemoryFiles(
  memoryDir: string,
  signal: AbortSignal,
): Promise<MemoryHeader[]> {
  try {
    const entries = await readdir(memoryDir, { recursive: true })
    const mdFiles = entries.filter(
      f => f.endsWith('.md') && basename(f) !== 'MEMORY.md',
    )

    const headerResults = await Promise.allSettled(
      mdFiles.map(async (relativePath): Promise<MemoryHeader> => {
        const filePath = join(memoryDir, relativePath)
        const { content, mtimeMs } = await readFileInRange(
          filePath,
          0,
          FRONTMATTER_MAX_LINES,
          undefined,
          signal,
        )
        const { frontmatter } = parseFrontmatter(content, filePath)
        return {
          filename: relativePath,
          filePath,
          mtimeMs,
          description: frontmatter.description || null,
          type: parseMemoryType(frontmatter.type),
        }
      }),
    )

    return headerResults
      .filter(r => r.status === 'fulfilled')
      .map(r => r.value)
      .sort((a, b) => b.mtimeMs - a.mtimeMs)  // 最新优先
      .slice(0, MAX_MEMORY_FILES)
  } catch {
    return []
  }
}
```

```typescript
const SELECT_MEMORIES_SYSTEM_PROMPT = `
You are selecting memories that will be useful to Claude Code as it processes a user's query.
Return a list of filenames for the memories that will clearly be useful (up to 5).
Only include memories that you are certain will be helpful.
- If unsure, do not include it.
- If no memories are clearly useful, return an empty list.

/**
 * 通过扫描记忆文件头并使用 AI 选择最相关的记忆
 * 返回最多 5 个最相关记忆的绝对路径
 */
export async function findRelevantMemories(
  query: string,
  memoryDir: string,
  signal: AbortSignal,
  recentTools: readonly string[] = [],
  alreadySurfaced: ReadonlySet<string> = new Set(),
): Promise<RelevantMemory[]> {
  const memories = (await scanMemoryFiles(memoryDir, signal))
    .filter(m => !alreadySurfaced.has(m.filePath))

  if (memories.length === 0) return []

  const selectedFilenames = await selectRelevantMemories(
    query,
    memories,
    signal,
    recentTools,
  )

  const byFilename = new Map(memories.map(m => [m.filename, m]))
  return selectedFilenames
    .map(filename => byFilename.get(filename))
    .filter((m): m is MemoryHeader => m !== undefined)
    .map(m => ({ path: m.filePath, mtimeMs: m.mtimeMs }))
}

async function selectRelevantMemories(
  query: string,
  memories: MemoryHeader[],
  signal: AbortSignal,
  recentTools: readonly string[],
): Promise<string[]> {
  const manifest = formatMemoryManifest(memories)

  // 排除正在使用的工具的参考文档
  const toolsSection = recentTools.length > 0
    ? `\n\nRecently used tools: ${recentTools.join(', ')}`
    : ''

  const result = await sideQuery({
    model: getDefaultSonnetModel(),
    system: SELECT_MEMORIES_SYSTEM_PROMPT,
    skipSystemPromptPrefix: true,
    messages: [{
      role: 'user',
      content: `Query: ${query}\n\nAvailable memories:\n${manifest}${toolsSection}`,
    }],
    max_tokens: 256,
    output_format: {
      type: 'json_schema',
      schema: {
        type: 'object',
        properties: {
          selected_memories: { type: 'array', items: { type: 'string' } },
        },
        required: ['selected_memories'],
        additionalProperties: false,
      },
    },
    signal,
    querySource: 'memdir_relevance',
  })

  const parsed = jsonParse(result.content.find(b => b.type === 'text')?.text || '{}')
  return parsed.selected_memories?.filter(f => validFilenames.has(f)) || []
}
```

```typescript
 * 计算记忆年龄（天数）

export function memoryAgeDays(mtimeMs: number): number {
  return Math.max(0, Math.floor((Date.now() - mtimeMs) / 86_400_000))

/**
 * 人类可读的年龄字符串
 * 模型不擅长日期计算，"47 days ago" 比 ISO 时间戳更能触发陈旧性推理
 */
export function memoryAge(mtimeMs: number): string {

  if (d === 0) return 'today'
  if (d === 1) return 'yesterday'
  return `${d} days ago`
}

    `Memories are point-in-time observations, not live state — ` +
    `claims about code behavior or file:line citations may be outdated. ` +
    `Verify against current code before asserting as fact.`

}
```

### 12.5.3 路径安全验证

团队记忆写入需要严格的安全验证，防止路径遍历攻击：

```typescript
// src/memdir/teamMemPaths.ts

/**
 * 安全验证错误
 */
export class PathTraversalError extends Error {
  constructor(message: string) {
    super(message)
    this.name = 'PathTraversalError'
  }
}

/**
 * 验证团队记忆写入路径的安全性
 * 1. 检查空字节、URL 编码遍历、Unicode 规范化攻击
 * 2. 使用 realpath 解析符号链接，确保实际路径仍在团队目录内
 */
export async function validateTeamMemWritePath(filePath: string): Promise<string> {
  if (filePath.includes('\0')) {
    throw new PathTraversalError(`Null byte in path: "${filePath}"`)
  }

  // 第一道防线：规范化 .. 段并检查字符串级别的包含关系
  const resolvedPath = resolve(filePath)
  const teamDir = getTeamMemPath()
  if (!resolvedPath.startsWith(teamDir)) {
    throw new PathTraversalError(`Path escapes team memory directory: "${filePath}"`)
  }

  // 第二道防线：解析符号链接并验证实际路径
  const realPath = await realpathDeepestExisting(resolvedPath)
  if (!(await isRealPathWithinTeamDir(realPath))) {
    throw new PathTraversalError(`Path escapes team memory directory via symlink: "${filePath}"`)
  }

  return resolvedPath
}

/**
 * 解析路径的最深现有祖先的符号链接
 * 处理目标文件可能不存在（即将创建）的情况
 */
async function realpathDeepestExisting(absolutePath: string): Promise<string> {
  const tail: string[] = []
  let current = absolutePath

  for (let parent = dirname(current); current !== parent; parent = dirname(current)) {
    try {
      const realCurrent = await realpath(current)
      return tail.length === 0 ? realCurrent : join(realCurrent, ...tail.reverse())
    } catch (e: unknown) {
      const code = getErrnoCode(e)
      if (code === 'ENOENT') {
        // 检查是否为悬空符号链接
        try {
          const st = await lstat(current)
          if (st.isSymbolicLink()) {
            throw new PathTraversalError(`Dangling symlink detected: "${current}"`)
          }
        } catch (lstatErr: unknown) {
          if (lstatErr instanceof PathTraversalError) throw lstatErr
        }
      } else if (code === 'ELOOP') {
        throw new PathTraversalError(`Symlink loop detected in path: "${current}"`)
      }
      tail.push(current.slice(parent.length + sep.length))
      current = parent
    }
  }

  return absolutePath
}
```

### 12.5.4 记忆提取 Agent

系统在每次对话结束时运行后台 Agent 提取值得记住的信息：

```typescript
// src/services/extractMemories/extractMemories.ts

/**
 * 在查询循环结束时运行记忆提取
 * 使用分叉 Agent 模式——共享主对话的提示缓存
 */
export async function executeExtractMemories(
  context: REPLHookContext,
  appendSystemMessage?: AppendSystemMessageFn,
): Promise<void> {
  await extractor?.(context, appendSystemMessage)
}

/**
 * 初始化记忆提取系统
 * 创建闭包捕获所有可变状态
 */
export function initExtractMemories(): void {
  // 闭包作用域的可变状态
  const inFlightExtractions = new Set<Promise<void>>()
  let lastMemoryMessageUuid: string | undefined  // 上次处理的消息游标
  let inProgress = false                           // 运行中标志
  let turnsSinceLastExtraction = 0                 // 自上次提取后的轮次
  let pendingContext: { context: REPLHookContext; appendSystemMessage?: AppendSystemMessageFn } | undefined

  async function runExtraction({ context, appendSystemMessage, isTrailingRun }): Promise<void> {
    const { messages } = context
    const memoryDir = getAutoMemPath()
    const newMessageCount = countModelVisibleMessagesSince(messages, lastMemoryMessageUuid)

    // 如果主 Agent 已经写入了记忆，跳过分叉 Agent
    if (hasMemoryWritesSince(messages, lastMemoryMessageUuid)) {
      lastMemoryMessageUuid = messages.at(-1)?.uuid
      return
    }

    // 节流：每 N 轮才运行一次
    if (!isTrailingRun) {
      turnsSinceLastExtraction++
      if (turnsSinceLastExtraction < getFeatureValue('tengu_bramble_lintel', 1)) {
        return
      }
    }
    turnsSinceLastExtraction = 0
    inProgress = true

    try {
      // 预注入记忆清单，避免 Agent 浪费一轮 ls
      const existingMemories = formatMemoryManifest(
        await scanMemoryFiles(memoryDir, createAbortController().signal),
      )

      // 构建提取提示
      const userPrompt = teamMemoryEnabled
        ? buildExtractCombinedPrompt(newMessageCount, existingMemories, skipIndex)
        : buildExtractAutoOnlyPrompt(newMessageCount, existingMemories, skipIndex)

      // 运行分叉 Agent
      const result = await runForkedAgent({
        promptMessages: [createUserMessage({ content: userPrompt })],
        cacheSafeParams,
        canUseTool: createAutoMemCanUseTool(memoryDir),
        querySource: 'extract_memories',
        forkLabel: 'extract_memories',
        skipTranscript: true,
        maxTurns: 5,  // 防止无限循环
      })

      // 更新游标
      lastMemoryMessageUuid = messages.at(-1)?.uuid

      // 提取写入的路径并通知用户
      const writtenPaths = extractWrittenPaths(result.messages)
      const memoryPaths = writtenPaths.filter(p => basename(p) !== 'MEMORY.md')

      if (memoryPaths.length > 0) {
        appendSystemMessage?.(createMemorySavedMessage(memoryPaths))
      }
    } catch (error) {
      logForDebugging(`[extractMemories] error: ${error}`)
    } finally {
      inProgress = false

      // 如果运行期间有新调用，执行尾部提取
      const trailing = pendingContext
      pendingContext = undefined
      if (trailing) {
        await runExtraction({ ...trailing, isTrailingRun: true })
      }
    }
  }

  extractor = async (context, appendSystemMessage) => {
    const p = executeExtractMemoriesImpl(context, appendSystemMessage)
    inFlightExtractions.add(p)
    try { await p } finally { inFlightExtractions.delete(p) }
  }
}
```

### 12.5.5 工具权限限制

记忆提取 Agent 的权限被严格限制：

```typescript
/**
 * 创建只能访问记忆目录的 canUseTool 函数
 * 允许：Read/Grep/Glob（无限制）、只读 Bash、Edit/Write（仅限记忆目录）
 */
export function createAutoMemCanUseTool(memoryDir: string): CanUseToolFn {
  return async (tool: Tool, input: Record<string, unknown>) => {
    // 允许 REPL（其内部操作会再次调用此函数）
    if (tool.name === REPL_TOOL_NAME) {
      return { behavior: 'allow', updatedInput: input }
    }

    // 允许 Read/Grep/Glob
    if ([FILE_READ_TOOL_NAME, GREP_TOOL_NAME, GLOB_TOOL_NAME].includes(tool.name)) {
      return { behavior: 'allow', updatedInput: input }
    }

    // 允许只读 Bash 命令
    if (tool.name === BASH_TOOL_NAME) {
      const parsed = tool.inputSchema.safeParse(input)
      if (parsed.success && tool.isReadOnly(parsed.data)) {
        return { behavior: 'allow', updatedInput: input }
      }
      return denyAutoMemTool(tool, 'Only read-only shell commands are permitted')
    }

    // 允许 Edit/Write 仅限于记忆目录
    if ([FILE_EDIT_TOOL_NAME, FILE_WRITE_TOOL_NAME].includes(tool.name) && 'file_path' in input) {
      const filePath = input.file_path
      if (typeof filePath === 'string' && isAutoMemPath(filePath)) {
        return { behavior: 'allow', updatedInput: input }
      }
    }

    return denyAutoMemTool(tool, `only read operations and writes within ${memoryDir} are allowed`)
  }
}
```

## 12.6 总结

Claude Code 的历史记录与记忆系统体现了以下设计智慧：

### 12.6.1 历史系统特点

1. **异步批量写入**：使用待刷新缓冲区和文件锁，平衡性能与数据安全
2. **智能存储**：小文本内联，大文本外部哈希存储，优化历史文件大小
3. **会话隔离**：当前会话历史优先，避免并发会话的历史混淆
4. **撤销支持**：支持中断时语义撤销，保持历史与实际操作一致

### 12.6.2 记忆系统特点

1. **类型约束**：四种记忆类型（user/feedback/project/reference），避免信息冗余
2. **可推导排除**：代码、Git 历史等可从项目状态推导的内容不存储
3. **文件优先**：Markdown 格式，便于版本控制和人工审查
4. **智能检索**：AI 辅助选择相关记忆，避免上下文膨胀
5. **新鲜度警告**：提示过时记忆，防止错误信息被当作事实
6. **双层作用域**：私有记忆与团队记忆分离，支持协作

### 12.6.3 安全考虑

1. **路径验证**：团队记忆写入时严格验证路径，防止遍历攻击
2. **符号链接检测**：使用 realpath 解析符号链接，防止逃逸
3. **权限限制**：记忆提取 Agent 只能写入记忆目录
4. **敏感数据排除**：明确禁止在团队记忆中存储敏感信息

这套系统在保持简单性的同时，提供了足够的智能来积累和利用长期记忆，是 AI 助手持久化能力的一个优秀参考实现。
