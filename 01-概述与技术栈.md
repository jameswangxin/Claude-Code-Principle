# 第1章：Claude Code概述与技术栈

## 1.1 Claude Code简介

### 1.1.1 产品定位

Claude Code 是 Anthropic 官方推出的命令行界面（CLI）工具，用于在终端环境中与 Claude 模型进行交互，执行软件工程任务。它能够编辑文件、运行命令、搜索代码库并协调复杂的工作流程。

Claude Code 的核心能力包括：

- **代码编辑**：通过 `FileEditTool`、`FileWriteTool` 等工具直接修改项目文件
- **命令执行**：通过 `BashTool` 在沙盒环境中执行 Shell 命令
- **代码搜索**：通过 `GrepTool`（基于 ripgrep）和 `GlobTool` 进行高效的代码搜索
- **智能代理**：通过 `AgentTool` 生成子代理执行特定任务
- **工作流自动化**：通过 Skill 系统和 Hook 机制实现可复用的工作流

### 1.1.2 架构规模

根据源代码分析，Claude Code 是一个大型 TypeScript 项目：

| 指标 | 数值 |
|------|------|
| 源文件数量 | ~1,900 个 |
| 代码行数 | 512,000+ 行 |
| 工具模块 | ~40 个 |
| 命令模块 | ~50 个 |
| UI 组件 | ~140 个 |

### 1.1.3 核心入口点

Claude Code 的启动入口定义在 `src/main.tsx` 中，使用 Commander.js 进行 CLI 参数解析：

```typescript
// src/main.tsx (简化示例)
import { feature } from 'bun:bundle'

// 并行预取优化：在模块加载前启动异步操作
startMdmRawRead()      // MDM 设置预取
startKeychainPrefetch() // Keychain 凭证预取

// Commander.js CLI 解析
const program = new Command()
program
  .name('claude')
  .version(VERSION)
  .option('--print', 'Print mode (non-interactive)')
  .option('--resume', 'Resume previous session')
  // ... 更多选项
```

启动时采用**并行预取策略**，通过 `startMdmRawRead()` 和 `startKeychainPrefetch()` 在重型模块评估之前并行执行 I/O 操作，显著优化冷启动时间。

## 1.2 核心技术栈分析

### 1.2.1 运行时环境：Bun

Claude Code 选择 Bun 作为运行时而非 Node.js，主要基于以下优势：

**1. 原生 TypeScript 支持**
```typescript
// 无需编译即可直接运行 .ts 文件
import { QueryEngine } from './QueryEngine.js'
```

**2. 特性标志系统（Feature Flags）**

Bun 提供了 `bun:bundle` 模块，支持编译时特性标志，实现死代码消除：

```typescript
import { feature } from 'bun:bundle'

// 条件导入：仅当 PROACTIVE 特性启用时才加载
const SleepTool = feature('PROACTIVE') || feature('KAIROS')
  ? require('./tools/SleepTool/SleepTool.js').SleepTool
  : null

// 协调器模式条件加载
const getCoordinatorUserContext = feature('COORDINATOR_MODE')
  ? require('./coordinator/coordinatorMode.js').getCoordinatorUserContext
  : () => ({})
```

主要特性标志包括：

| 标志名称 | 功能描述 |
|---------|---------|
| `PROACTIVE` | 主动模式支持 |
| `KAIROS` | 高级助理功能 |
| `BRIDGE_MODE` | IDE 桥接模式 |
| `DAEMON` | 守护进程模式 |
| `VOICE_MODE` | 语音输入模式 |
| `AGENT_TRIGGERS` | 代理触发器 |
| `MONITOR_TOOL` | 监控工具 |
| `COORDINATOR_MODE` | 多代理协调器 |
| `HISTORY_SNIP` | 历史压缩 |

**3. 高性能包管理**

Bun 的包管理器比 npm 快 20-30 倍，这对于 CI/CD 和开发体验至关重要。

  // 输入 Schema（Zod）
  inputSchema: z.object({
    command: z.string(),
    timeout: z.number().optional(),

    // 1. 解析命令
    // 2. 检查权限
    // 3. 执行命令（可选沙盒）

### 1.3.4 查询引擎架构

`QueryEngine` 是 Claude Code 的核心，负责管理 LLM API 调用的生命周期：

```typescript
// src/QueryEngine.ts
export class QueryEngine {
  private config: QueryEngineConfig
  private mutableMessages: Message[]
  private abortController: AbortController
  private permissionDenials: SDKPermissionDenial[]
  private totalUsage: NonNullableUsage
  private readFileState: FileStateCache

  constructor(config: QueryEngineConfig) {
    this.config = config
    this.mutableMessages = config.initialMessages ?? []
    this.abortController = config.abortController ?? createAbortController()
    this.permissionDenials = []
    this.totalUsage = EMPTY_USAGE
  }

  async *submitMessage(
    prompt: string | ContentBlockParam[],
    options?: { uuid?: string; isMeta?: boolean },
  ): AsyncGenerator<SDKMessage, void, unknown> {
    // 1. 获取系统提示词
    const { defaultSystemPrompt, userContext, systemContext } =
      await fetchSystemPromptParts({ tools, mainLoopModel, ... })

    // 2. 处理用户输入
    const { messages, shouldQuery, allowedTools } = await processUserInput({
      input: prompt,
      mode: 'prompt',
      context: processUserInputContext,
    })

    // 3. 执行查询循环
    for await (const event of query({ messages, tools, ... })) {
      yield event
    }
  }
}
```
